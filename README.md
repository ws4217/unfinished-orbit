# UNFINISHED ORBIT／未完成的轨道

开发：ws4217 · 版本：`1.0.4`

已下载运行包？解压后运行 `node serve.mjs`。本地启动、端口和托管设置见[运行与部署](LOCAL-README.md)。

## 从源码运行

安装 Node.js 22 或更新版本，在仓库根目录执行：

```sh
npm ci
npm run build
npm run preview
```

打开 <http://127.0.0.1:4217/>。可独立部署的游戏文件位于 `dist/`。

## 操作

- **键盘**：Enter 开始；WASD 或方向键移动；Z 确认，X 补全文字或返回；C 打开菜单，J 查看日志。Esc 可退出可选对白或挂断电话。
- **手机**：横屏游玩。左侧摇杆移动，右侧 Z / X 确认或返回；长按 X 可挂断。菜单可点按，校准卡可拖动，限时方向题用屏幕十字键。
